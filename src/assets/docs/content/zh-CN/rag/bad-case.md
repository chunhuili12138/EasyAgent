## 功能概述

**Bad Case 分析**集中管理用户在智能会话中提交的负面反馈。每条记录关联一条助手消息，保存当轮问题、AI 回答、反馈类型、补充说明和检索结果，供 Agent 管理员分析根因并填写参考正确答案。

当前页面是单条查看与标注工具，不提供批量标注、删除、重新执行、导出或自动修复能力。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（后端要求 `AGENT_ADMIN` 或 `SYS_ADMIN`）。
- **产生条件**：用户在智能会话中对助手回答提交负面反馈，并选择一个有效的反馈类型；同一消息只创建一条 Bad Case。

## 进入路径

主菜单：**Agent 管理 → Bad Case 分析**。

## 操作步骤

### 1. 查看统计与筛选

- 顶部卡片显示当前租户的**待标注 / 已标注**数量，不随列表筛选变化。
- 关键字只匹配**用户问题**，不搜索 AI 回答或反馈说明。
- 状态可选待标注、已标注；日期范围按记录创建日期筛选。
- 点击**查询**应用条件；**重置**会清空条件并返回第 1 页。
- 列表支持 10 / 20 / 50 / 100 条分页，默认按创建时间倒序。

### 2. 查看详情并判断根因

点击**详情**查看：

- 会话 ID、消息 ID 与当前状态；
- 完整用户问题和 AI 回答；
- 反馈类型与用户补充说明；
- 当轮保存的检索结果；
- 已填写的正确回答。

建议按以下顺序判断：

1. 检索结果为空：检查知识缺失、文档处理/索引状态、权限过滤或提问表达。
2. 检索结果相关但回答错误：检查提示词、上下文裁剪、引用门槛和模型生成。
3. 事实正确但反馈为格式或指令问题：调整 Skill 的 LLM 提示、输出 Schema 或回答展示。
4. 涉及工具/数据查询：再到操作审计或 SQL 审计核对执行记录。

### 3. 标注正确回答

1. 对 `pending` 记录点击**标注**；已标注记录在页面上不再显示标注按钮。
2. 核对问题、原回答、反馈类型和说明。
3. 输入非空的**正确回答**，内容应直接回答原问题，并说明必要依据与边界。
4. 点击**保存**。系统去除首尾空白，记录标注人和标注时间，并把状态改为 `labeled`。

标注不会自动修改原会话消息，不会写入知识库、经验池或 Skill，也不会触发重新回答。要修复线上效果，仍需按根因调整对应配置或内容后重新测试。

## 反馈类型

| 页面类型 | 存储值 | 使用场景 |
|---|---|---|
| 事实不符 | `factual_mismatch` | 与可信资料或业务事实冲突 |
| 未遵循指令 | `instruction_not_followed` | 忽略用户指定的范围、格式或步骤 |
| 格式问题 | `format_issue` | 表格、字段、段落或可读性不符合预期 |
| 内容错误 | `content_error` | 推理、计算或操作说明错误 |
| 回答不完整 | `incomplete_answer` | 遗漏关键事实、条件或后续动作 |
| 回答不相关 | `irrelevant_answer` | 回答偏离问题 |
| 其他 | `other` | 不属于以上类型 |

## 状态

| 存储状态 | 页面含义 | 当前页面能力 |
|---|---|---|
| `pending` | 待标注 | 可查看、可填写正确回答 |
| `labeled` | 已标注 | 可查看，不提供再次编辑按钮 |
| `exported` | 已导出（预留） | 后端保留该状态统计，但当前页面没有筛选、导出或推进操作 |

## 常见问题

**用户点了负面反馈，为什么没有记录？**
请确认反馈提交成功且选择了有效类型。系统只为助手消息的负面反馈创建记录；中性/正面反馈不会创建，同一消息重复提交也不会重复创建。

**为什么关键字搜不到反馈说明中的文字？**
当前关键字只查询用户问题。可结合日期、状态缩小范围后查看列表中的反馈说明。

**标注后会立即修正回答吗？**
不会。正确回答是质量治理参考，不会自动回写任何运行配置。

**可以删除、导出或重新打开已标注记录吗？**
当前页面不支持这些操作。`exported` 是保留状态，并不代表本页已有可用导出流程。

## 使用边界

- 数据按租户隔离；问题、回答和检索结果可能包含敏感业务信息，应按最小权限分配 Agent 管理权限。
- 正确回答应基于已核实资料，不能把猜测写成标准答案。
- 同类问题批量出现时，应先修复共同根因，再用正常用户对话回归，不要只逐条填正确回答。
- 检索结果是当时保存的快照，不能代替对当前知识库、Schema、工具和 Skill 配置的现场核查。
