## 功能概述

**经验池** 沉淀 Agent 会话中形成的优质问答经验（问题 + 答案 + 引用资料）。智能问答时，系统会优先命中经验池中的经验，提升同类问题的回答质量与效率。本页为管理视图：查看、筛选与淘汰经验，不支持手工创建。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（`rag:experience:list` 权限）。
- **前置条件**：已有会话产生过高质量问答且被系统沉淀（由后台自动评估写入）。

## 进入路径

主菜单：**Agent 管理 → 经验池**。

## 操作步骤

### 1. 查看经验

- 顶部统计卡展示经验**总计 / 启用 / 已淘汰**数量；
- 列表展示问题、质量分、命中次数、可见性与最后命中时间；
- 点击 **详情** 查看完整答案与引用资料（文件名、片段）。

### 2. 筛选经验

可按关键字、可见性（公开/部门/岗位/用户）与最低质量分（0–1）组合筛选，用于评估经验质量分布。

### 3. 淘汰经验

点击 **删除** 淘汰不再需要的经验；删除后该经验将不再参与问答命中。

> **注意** 删除不可恢复；仅可删除当前账号有权限删除的经验（按钮置灰表示不可删）。

## 配置项说明

### 列表字段

| 字段 | 说明 |
|---|---|
| 问题 | 沉淀经验的原始问题 |
| 质量分 | 0–1，越高代表回答越可靠 |
| 命中 | 被问答命中的次数 |
| 可见性 | 经验可被谁命中（public / department / post / user） |
| 最后命中 | 最近一次被使用的时间 |

## 常见问题

**经验池里的经验是怎么产生的？**
系统根据会话回答质量与用户反馈自动评估沉淀；人工无法直接添加。

**如何让更多问题命中经验池？**
提升知识库数据质量、鼓励用户对优质回答给予正面反馈，都有助于优质经验沉淀。

**经验会过期吗？**
不会自动过期；质量下降或被删除后停止命中。

## 使用提示与边界

- 经验命中遵循 ACL：用户只能命中其可见范围内的经验。
- 经验是问答的**参考答案**，最终回答仍会结合当前检索结果，避免陈旧经验误导。
