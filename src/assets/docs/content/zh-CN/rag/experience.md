## 功能概述

**经验池**自动保存符合质量门槛的知识问答结果，包括问题、答案、引用和来源分块。后续出现**相同问题**时，系统会先校验租户、用户可见范围、来源文档和引用是否仍有效，再决定是否直接复用，减少重复检索与生成。

本页是管理视图，只支持查看、筛选和淘汰，不支持手工新建、编辑或恢复。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（后端要求 `AGENT_ADMIN` 或 `SYS_ADMIN`，菜单通常对应 `rag:experience:list`）。
- **产生条件**：知识问答已得到带有效引用的可靠回答，且质量评估通过。使用会话附件生成的回答不会沉淀到经验池。

## 进入路径

主菜单：**Agent 管理 → 经验池**。

## 操作步骤

### 1. 查看统计与列表

- 顶部卡片显示当前租户的**总计 / 启用 / 已淘汰**数量；卡片统计不随下方筛选条件变化。
- 列表默认按最后命中时间、创建时间倒序展示，每页可选 10 / 20 / 50 / 100 条。
- 列表包含问题、质量分、命中次数、可见性和最后命中时间。

### 2. 筛选经验

1. 在关键字框输入问题中的文字；关键字只匹配**问题文本**。
2. 可选择公开、部门、岗位或用户可见性。
3. 可填写 0～1 的最低质量分，步长为 0.05。
4. 点击**查询**；点击**重置**清除全部条件并返回第 1 页。

### 3. 查看详情

点击**详情**查看完整问题、答案、可见性和引用资料。引用可包含文件名、定位信息与片段；旧记录或引用 JSON 无法解析时，页面会回退显示来源分块 ID。

详情中的引用是经验创建时保存的快照。真正复用前，后端会重新检查来源分块和文件是否仍存在，并校验当前用户 ACL；来源被删除或权限变化后，即使记录仍在列表中也不会被复用。

### 4. 淘汰经验

1. 仅启用状态的记录可以点击**删除**。
2. 确认后，系统先撤销 Redis 缓存，再把数据库状态改为已淘汰。
3. 淘汰成功后记录仍保留在列表和统计中，但不再参与问答命中，删除按钮会置灰。

如果缓存撤销失败，后台会拒绝淘汰并保留原状态，避免数据库与缓存状态不一致。当前页面没有恢复入口。

## 字段与运行规则

| 字段 | 说明 |
|---|---|
| 问题 | 形成经验时使用的检索问题 |
| 质量分 | 系统根据答案完整度和引用覆盖等信号计算，范围 0～1；不是人工评分 |
| 命中次数 | 经验成功复用的累计次数 |
| 可见性 | 根据来源文档权限归纳为 public / department / post / user |
| 最后命中 | 最近一次成功复用时间；从未复用时显示 `-` |
| 启用/已淘汰 | 启用记录可参与复用；已淘汰记录只保留用于追溯 |

经验复用不是语义相似检索。当前实现按原问题生成精确键，只有相同问题进入候选；候选还必须同时满足启用、当前用户可见、来源仍完整、引用有效和答案可安全复用。

## 常见问题

**为什么知识问答成功了却没有新增经验？**
回答可能缺少有效引用、质量未达到门槛、属于资料不足/失败回答，或本轮使用了会话附件。经验沉淀是后台自动判断，页面不能强制创建。

**为什么表达相近的问题没有命中？**
经验池当前按相同问题的精确键匹配，不进行相似句召回。表达变化时会正常走知识检索与生成。

**用户点赞会直接创建或提高经验分吗？**
不会。当前反馈接口用于保存消息反馈和创建负面 Bad Case；经验创建与质量分由回答和引用质量评估决定。

**为什么记录还在，但问答没有复用？**
记录可能已淘汰，或来源文档/分块已删除、当前用户权限或引用完整性不再满足复用条件。

## 使用提示与边界

- 经验按租户隔离，复用时重新执行当前用户 ACL 校验；列表中的可见性表示问答复用范围，不限制 Agent 管理员查看本租户记录。
- 淘汰是软停用，不删除历史记录；页面当前不能重新启用。
- 经验答案可能随业务规则过时。更新或下架知识文档后，应抽查相关经验，必要时主动淘汰。
- 当前复用校验关注来源记录是否存在与 ACL，不单独按索引状态过滤。只执行“取消索引”而未删除来源时，应同步淘汰相关经验，避免继续返回旧答案。
- 经验命中会直接返回保存的答案与引用，不会再调用 LLM 改写，因此应优先淘汰措辞过时、信息不完整或不适合直接复用的记录。
