## 功能概述

**操作审计**用于追溯智能会话中的 HITL 人工确认：系统在高风险步骤执行前保存待确认记录，用户确认、取消或超时后更新状态。本页只负责查询与查看，不提供确认、驳回、修改或删除操作。

当前会话执行器会对 `action` 类型的 API 工具触发 HITL。页面同时保留 `sql_exec` 类型筛选，用于兼容已有或其他执行链写入的 SQL 审批记录；普通 NL2SQL 查询不会因为出现在这里而自动要求审批，其执行情况应到 **SQL 审计**查看。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（后端要求 `AGENT_ADMIN` 或 `SYS_ADMIN`）。
- **前置条件**：智能会话中已产生过操作型 API 的待确认请求，或系统中已有兼容的审批记录。

## 进入路径

主菜单：**Agent 管理 → 操作审计**。

## 操作步骤

### 1. 查看统计与列表

- 顶部卡片显示当前租户的**总计 / 已确认 / 已取消**数量；统计不随列表筛选变化。
- 超时数量由后端统计，但当前顶部没有单独卡片，可通过状态筛选查看。
- 列表显示操作类型、工具编码、风险等级、状态、处理用户和创建时间。
- 默认按创建时间倒序，支持 10 / 20 / 50 / 100 条分页。

### 2. 筛选记录

可组合以下条件：

| 条件 | 说明 |
|---|---|
| 用户 | 从当前租户用户列表选择；对已处理记录通常表示作出确认/取消决策的用户 |
| 操作类型 | API 调用 `api_call` 或 SQL 执行 `sql_exec` |
| 状态 | 待确认、已确认、已取消、超时 |
| 日期范围 | 按审批记录创建日期筛选 |

改变下拉框或日期会立即查询，也可以点击**查询**；点击**重置**清除全部条件并返回第 1 页。

### 3. 查看与复制详情

点击**详情**查看：

- 操作类型、工具编码、风险等级和状态；
- 工具输入：创建审批时冻结的步骤配置/参数快照；
- 取消原因：用户拒绝、执行中断、服务重启或超时等原因；
- 上下文快照：审批创建时已完成步骤或挂起执行状态的摘要。

工具输入和上下文以格式化 JSON 展示，可点击**复制**。复制内容与页面展示一致，会再次执行前端字段脱敏。

### 4. 关联问题排查

1. `pending` 长时间未处理：回到原智能会话检查待确认弹窗和 Redis/HITL 状态。
2. `cancelled`：查看取消原因，区分用户主动拒绝、原执行已结束、服务重启或系统异常。
3. `timeout`：审批超过平台等待时限，原执行通常不能继续使用该次确认。
4. `confirmed` 但外部操作失败：操作审计只证明审批通过，还需检查会话步骤结果、外部接口日志和工具配置。

## 字段与状态

### 操作类型

| 存储值 | 页面含义 | 当前来源 |
|---|---|---|
| `api_call` | API 调用 | 智能会话中 `action` 工具的 HITL |
| `sql_exec` | SQL 执行 | 兼容已有/其他执行链写入；普通 NL2SQL 主要记录在 SQL 审计 |

### 状态

| 状态 | 说明 |
|---|---|
| `pending` | 等待用户在原会话中确认或取消 |
| `confirmed` | 用户已确认，执行链可以继续；不代表外部调用最终成功 |
| `cancelled` | 用户拒绝或系统因中断、冲突等原因取消 |
| `timeout` | 在等待时限内未完成确认 |

### 风险等级

`low`、`medium`、`high` 是审批步骤携带的展示元数据，未显式提供时默认 `medium`。它用于帮助用户理解风险，不会代替工具的 `query/action` 分类，也不会自动改变权限或审批规则。

## 脱敏规则

后端和前端会递归遮盖 JSON 中键名包含以下词的字段：`password`、`secret`、`token`、`api-key`/`api_key`、`authorization`、`cookie`。

该规则按**字段名**识别：秘密若放在普通字段名下，或内容不是合法 JSON，不能保证自动遮盖。因此工具参数、模板和上下文中本就不应保存认证密钥；认证信息应放在 API 工具的加密认证配置中。

## 常见问题

**为什么 SQL 查询没有出现在操作审计？**
操作审计是 HITL 审批记录。普通 NL2SQL 只读查询无聊天 HITL，请到 SQL 审计查看成功、拦截和失败记录。

**为什么已确认记录的外部业务仍没有成功？**
确认只允许执行继续。审批后还可能因工具变更、参数校验、SSRF、认证、超时、业务状态码或响应映射失败。

**能在本页补做确认或修改状态吗？**
不能。审批只能在原会话的 HITL 流程中处理，本页记录不可编辑、不可删除。

## 使用边界

- 记录按租户隔离，但详情可能含业务参数和上下文，仍应按最小权限控制 Agent 管理角色。
- 不要把“已确认”等同于“执行成功”，应结合会话执行结果和外部系统日志形成完整证据链。
- 页面没有按会话 ID、消息 ID 或工具输入关键字筛选，排查时可先按用户、时间和工具编码缩小范围。
- 脱敏是展示防线，不是秘密管理方案；不要在普通参数中传递长期密钥。
