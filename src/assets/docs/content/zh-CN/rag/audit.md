## 功能概述

**操作审计** 记录 Agent 执行过程中的人工确认（HITL）记录，包括工具调用（API）与 SQL 执行两类高风险操作：谁在什么时间确认/取消了什么操作，以及当时的工具输入与上下文快照，满足追溯与合规要求。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（`rag:audit:list` 权限）。
- **前置条件**：会话中已产生过需要审批的操作（调用 action 类工具或执行 SQL）。

## 进入路径

主菜单：**Agent 管理 → 操作审计**。

## 操作步骤

### 1. 筛选审计记录

- 顶部统计卡展示**总计 / 已确认 / 已取消**数量；
- 可按**用户、操作类型、状态、日期范围**组合筛选。

### 2. 查看记录详情

点击 **详情** 查看：

- 操作类型、工具/代码、风险等级、状态、发起用户与时间；
- **工具输入**：JSON 格式化展示，**敏感字段自动脱敏**（密码、Token、API Key、Authorization 等显示为 `******`），可一键复制；
- **取消原因**：被取消操作附带的理由；
- **上下文快照**：当时的会话上下文，同样脱敏。

## 配置项说明

### 操作类型

| 类型 | 说明 |
|---|---|
| api_call | 外部 API 调用 |
| sql_exec | NL2SQL 查询执行 |

### 状态

| 状态 | 说明 |
|---|---|
| 待确认 | 等待审批人处理 |
| 已确认 | 审批人批准，任务继续 |
| 已取消 | 审批人拒绝，任务终止 |
| 超时 | 超过时限未处理 |

### 风险等级

| 等级 | 含义 |
|---|---|
| 低 | 查询类、只读操作 |
| 中 | 一般性外部调用 |
| 高 | 数据变更或高影响操作 |

## 常见问题

**审计记录里的密钥安全吗？**
详情展示会自动脱敏敏感字段；复制的是脱敏后的内容，原值不会通过前端展示。

**为什么有的操作没有审计记录？**
只有**操作类（action）工具调用与 SQL 执行**等高风险操作需要审批并记录；普通查询类调用不强制记录。

**超时的审批会怎样？**
超过时限未处理自动标记"超时"，对应任务按平台策略处理（通常为终止或降级）。

## 使用提示与边界

- 审计记录不可修改、不可删除，用于合规追溯。
- 审批决策请在会话中及时处理，避免操作超时导致任务失败。
