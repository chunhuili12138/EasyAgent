## 平台是什么

EasyAgent 是一个面向企业的 **RAG 智能问答与 Agent 自动化平台**。您可以将企业文档、数据库和外部 API 接入平台，通过知识库问答与自动化工作流，让 AI 承担知识检索、数据分析与重复性事务处理工作。

平台围绕五条核心能力构建：

| 能力 | 说明 |
|---|---|
| 多租户系统管理 | 每个租户独立组织架构与数据隔离，支持用户、部门、岗位管理与租户级配额控制 |
| 文档处理 | 上传 PDF、Word、PPT、Excel 和图片；手动提交解析、数据处理，审核结果后再导入 Elasticsearch |
| RAG 知识问答 | 混合检索 + 重排 + 引用证据，回答结果附出处，支持会话记忆与附件 |
| Agent 能力编排 | 通过 Skill 编排"检索、查库、调接口、问大模型"等步骤，高风险操作需人工审批（HITL） |
| 自动化中心 | 可视化编排跨系统工作流，按定时、内部事件、Webhook 或审批回调自动执行，失败可重试与恢复 |

> **提示** 本文档面向租户内各角色使用用户，系统级管理员独有功能不在本手册范围内。

## 使用流程

### 快速上手

```flow
登录平台
上传文档并手动提交解析
审核数据处理结果并导入知识库
发起智能会话提问
查看引用与反馈结果
```

### 完整使用路径

1. **登录平台**：使用租户管理员分配的账号密码登录，必要时在右上角切换到所属租户。
2. **准备知识库（文档处理）**：在"文档处理 → 文件管理"上传文档，手动发起解析；解析成功后到"解析管理"提交数据处理，审核并修正 Chunk 后，在"数据处理"点击"导入知识库"写入 Elasticsearch。系统没有单独创建知识库的操作，知识库由已导入的检索数据构成。
3. **配置问答能力（Agent 管理）**：由具备 Agent 管理权限的用户配置数据源、Skill、API 工具与经验池，控制 AI 能做什么、能查什么、需要谁审批。
4. **使用智能会话（Agent 工作台）**：发起会话提问，答案会附上知识库引用来源；可在会话中上传附件限定检索范围。
5. **编排自动化（自动化中心）**：将重复性流程（如定时汇总、内部事件、Webhook 或审批回调处理）编排为工作流，发布后再配置触发器，异常可人工干预。

## 角色与权限

| 角色 | 职责 | 主要功能范围 |
|---|---|---|
| 租户管理员 | 维护本租户组织架构与账号 | 用户、部门、岗位管理 |
| 文档处理专员 | 管理知识库与文档处理链路 | 知识库、文件、解析、数据处理 |
| 智能问答用户 | 使用知识问答能力 | Agent 工作台智能会话 |
| Agent 管理员 | 维护 Agent 能力与自动化 | Skill、数据源、工具、经验池、审计、自动化中心 |

> **注意** 具体菜单与操作权限由租户管理员通过角色分配决定，页面可能只显示您有权限的功能。

## 常见问题

**为什么在智能会话中问不到文档内容？**
请先确认文件已经完成解析和数据处理，并在"数据处理"中显示为"已入库（indexed）"；同时确认当前用户有权访问该文档。

**上传的文档解析失败了怎么办？**
在"解析管理"中查看失败原因并触发重试；若多次失败，请检查文件格式与大小是否在支持范围内。

**会话回答没有引用来源？**
当检索证据不充分时，平台会保守回答并明确说明，避免编造内容；可尝试调整提问措辞或补充知识库内容。

## 使用提示

- 文档、数据源、API 工具等资源均受 ACL 与租户隔离保护，权限由租户管理员统一配置。
- 涉及外部系统的高风险操作会进入人工审批（HITL），审批通过后才继续执行。
- 自动化引擎是否启用由平台配置项决定；引擎关闭时需要联系平台管理员，启用后仍需发布工作流并启用触发器。
