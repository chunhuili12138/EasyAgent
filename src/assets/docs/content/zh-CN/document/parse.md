## 功能概述

**解析管理** 是文档处理链路的第二站：把上传的原始文件解析为结构化 Markdown，并进行质量评估。您可以查看解析出的内容、解析质量指标，确认无误后**提交数据处理**，进入切片与向量化阶段。

## 适用角色与前置条件

- **适用角色**：文档处理专员（`document:parse:list` 权限）。
- **前置条件**：文件已完成上传（文件管理页"解析成功"或"未解析"状态）。

## 进入路径

主菜单：**文档处理 → 解析管理**。页面右上角 **?** 按钮可随时打开"文档解析操作指南"。

## 操作步骤

### 1. 发起解析

在"文件管理"页点击 **解析 / 批量解析** 后，任务会出现在本页列表中。也可在本页对"解析失败"的记录点击 **重试**。

### 2. 检查解析结果

- **查看内容**：点击操作列 **查看内容**，查看解析出的 Markdown；点击 **编辑** 可人工修正内容（保存后不会重算质量评分）。
- **查看指标**：若该行存在解析详情，点击 **指标** 查看解析器类型、OCR 页数、预处理与回退记录等指标。

### 3. 提交数据处理

- 解析状态为 **解析成功**（done）且未处理时，点击 **提交处理**；
- 系统会提示该文件的质量评分（0–100 分），确认后进入数据处理队列；
- 支持勾选多行后 **批量处理(N)**（仅对解析成功且未处理的行生效）。

### 4. 重新处理与重试

- **重新处理**：处理已完成时可用，用于内容有变更后重新生成 Chunk（若已入库会同步清空旧 Chunk 与检索数据）。
- **重试处理**：处理失败时可用。

### 5. 删除解析记录

删除后会同步删除处理结果与知识库检索数据，文件恢复"未解析"状态，可重新发起解析。

## 状态说明

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| 待解析 / 解析中 | 任务排队或执行中（每 20 秒自动刷新） | 无 |
| 解析成功 | 解析完成，质量评分展示为绿（≥70）/橙（≥50）/红（<50） | 提交处理、查看内容、指标 |
| 解析失败 | 解析异常 | 重试、删除 |

### 处理状态

| 状态 | 含义 |
|---|---|
| 未处理 | 尚未提交数据处理 |
| 处理中 | 数据处理执行中 |
| 已处理 | 数据处理完成（可在数据处理页查看结果并入库） |
| 处理失败 | 处理异常，可重试 |

## 质量评分参考

| 分数区间 | 颜色 | 建议 |
|---|---|---|
| ≥ 70 | 绿色 | 可直接提交处理 |
| 50 – 69 | 橙色 | 建议查看内容，修正明显问题 |
| < 50 | 红色 | 建议重新解析或检查原文件质量 |

> **注意** 人工编辑解析内容后质量评分保持不变，评分仅供参考；实际是否入库由您在数据处理页最终确认。

## 常见问题

**提交处理时提示"执行队列已满"？**
系统已自动保留任务为待处理，稍后会重新调度，无需重复提交。

**提示"该任务已经在排队或执行中"？**
任务已提交或正在执行，请勿重复操作，等待状态刷新即可。

**为什么要重新处理？**
重新处理会按最新解析内容重新生成 Chunk、摘要与 QA；若已入库，旧版本会被替换。

## 使用提示与边界

- 人工修改解析 Markdown 不会重新触发质量评估，请谨慎编辑并保存。
- 解析失败重试不保证成功：图片模糊、扫描件质量差或格式异常时，建议检查原文件。
- 删除解析记录是不可逆操作，会级联删除处理结果与知识库数据。
