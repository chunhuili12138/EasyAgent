## 功能概述

**文件管理** 是文档处理链路的第一站：负责文件上传、元数据登记与访问权限（ACL）设置。上传完成后可发起解析，把文件交给解析管理生成结构化内容。

支持批量上传（拖拽/选择）、批量解析、批量设置密级，以及文件的下载、删除与重新解析。

## 适用角色与前置条件

- **适用角色**：文档处理专员（`document:file:list` 权限）。
- **前置条件**：租户内已存在部门、岗位和用户数据（用于设置授权范围）；对象存储服务可用。

## 进入路径

主菜单：**文档处理 → 文件管理**。

## 操作步骤

### 1. 上传文件

1. 点击右上角 **上传文件** 按钮，打开上传弹窗。
2. 点击或拖拽选择文件（支持 PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX、TXT、MD、HTML、CSV 及常见图片格式，单个文件最大 **50MB**）。
3. 填写元数据（可选）：年份、文档类型、部门、岗位，并设置**密级**（默认"公开访问"）。
4. 选择授权范围：密级为"特定部门/特定岗位/特定用户"时，需选择对应的授权对象。
5. 点击确认，系统直接上传至对象存储；上传列表会显示逐项进度，单个文件失败时可单独重试。若批次预检或直传凭证申请失败，请按提示重新提交该批次。

> **提示** 系统按“当前租户 + 文件内容 MD5”判断重复，文件名不是去重条件。重复内容会被拒绝上传；如需重新上传，请使用新内容，或先处理已有文件记录。

### 2. 发起解析

- **单文件**：在操作列点击 **解析**（已解析文件显示 **重新解析**）。
- **批量**：勾选多个文件后点击 **批量解析(N)**。
- 若所选文件已存在解析结果，系统会二次确认是否**覆盖重解析**。

### 3. 设置密级（ACL）

- 点击操作列 **密级** 可修改单个文件的访问范围；
- 勾选多行后点击 **密级(N)** 可批量修改。

> **注意** 修改密级会立即删除该文件在 Elasticsearch 中的检索数据，并将原处理任务恢复为"完成"。如需继续检索，必须在"数据处理"页重新导入（更新知识库），新的密级才会进入检索数据。

### 4. 其他操作

- **下载**：操作列点击下载，浏览器新窗口打开原文件。
- **删除**：删除文件后，解析记录与处理结果会同步清理，不可恢复。

## 配置项说明

### 上传元数据

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 年份 | 否 | 当前年份 | 用于知识库按年份检索与过滤 |
| 文档类型 | 否 | 空 | 批复、通知、报告、合同、手册、论文、标准等 22 类，可输入新建 |
| 部门 | 否 | 空 | 树形选择；选择后联动加载该部门下的岗位 |
| 岗位 | 否 | 空 | 仅在所选部门下可选 |
| 密级 | 是 | 公开访问 | 公开 / 特定部门 / 特定岗位 / 特定用户 |
| 授权部门/岗位/用户 | 按密级 | 空 | 密级非公开时必选对应授权对象（支持多选） |

### 解析状态

| 状态 | 含义 |
|---|---|
| 未解析 | 文件已上传，尚未提交解析 |
| 解析中 | 解析任务执行中（页面每 20 秒自动刷新） |
| 解析成功 | 解析完成，可进入解析管理提交数据处理 |
| 解析失败 | 解析异常，可重试或删除后重新上传 |

## 常见问题

**为什么上传后文件状态一直是"未解析"？**
上传只完成文件登记，需要手动点击 **解析**（或批量解析）才会进入解析流程。

**上传失败（failed）怎么办？**
弹窗会显示首个失败原因；常见为网络中断或文件超过 50MB，可重试；若文件格式不受支持，请转换为支持的格式后上传。

**如何让一个文件仅对某个部门可见？**
在"密级"中选择"特定部门"并勾选目标部门即可；文件解析入库后，检索结果会按 ACL 自动过滤。

## 使用提示与边界

- 文件删除会级联删除解析与处理结果，操作前请确认不再需要。
- 密级属于文档级控制；知识库检索时还会叠加用户所属部门、岗位的过滤。
- 支持断点续传？暂不支持，大文件建议拆分上传。
