## 功能概述

**数据处理** 是文档处理链路的核心：对解析后的内容执行**文本切分（Chunk）→ 标签提取 → 数据存库 → 摘要生成 → 问题生成（QA）**，产出结构化的知识切片。您可以在本页**逐块审核与人工修正**（正文、摘要、标签、QA），确认后**导入知识库**（生成向量写入 Elasticsearch），供智能问答检索。

## 适用角色与前置条件

- **适用角色**：文档处理专员（`document:process:list` 权限）。
- **前置条件**：解析管理页中已有"解析成功"且未处理的记录。

## 进入路径

主菜单：**文档处理 → 数据处理**。页面右上角 **?** 按钮可打开"数据处理操作指南"。

## 操作步骤

### 1. 提交处理

在"解析管理"页点击 **提交处理 / 批量处理**，任务进入本页列表并展示分步进度（切分 → 标签 → 存库 → 摘要 → QA）与排队位置。

### 2. 审核与修正结果

1. 状态为 **完成**（done）后，点击 **结果** 打开全屏结果弹窗。
2. 左侧为 Chunk 树：父块/子块按结构层级展示，节点颜色圆点表示质量分（≥85 绿、65–84 橙、<65 红），支持按内容搜索定位。
3. 右侧四个页签分别查看/编辑：**内容**、**摘要**、**标签**、**QA**。
4. 点击 **编辑当前 Chunk** 修改，完成后 **保存当前编辑**；切换 Chunk 前若未保存会提示确认。

> **提示** 标签页包含文档继承的标签（年份、文档类型、部门、岗位、密级，只读）与可编辑的关键词、自定义标签（键值对）。部分标签键受保护，不可覆盖。

### 3. 导入知识库

- 状态为 **完成** 时，点击 **导入知识库**，系统生成向量并写入 Elasticsearch（大文件耗时较长，超时上限 10 分钟）；
- 状态为 **已入库** 时，按钮变为 **更新知识库**，用当前结果替换已入库版本。

### 4. 失败处理

- 状态为 **失败** 时点击 **重试** 重新处理；
- 也可在解析管理页重新处理或删除后重新发起。

### 5. 删除

删除处理记录会同步删除知识库检索数据，解析记录恢复"未处理"状态。

## 状态说明

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| 等待处理 | 已提交，排队中 | 无（可查看排队位置） |
| 处理中 | 正在执行切片/标签/摘要/QA | 无 |
| 入库中 | 正在生成向量写入 ES | 无 |
| 完成 | 处理完成，尚未入库 | 结果、导入知识库 |
| 已入库 | 已写入知识库 | 结果、更新知识库 |
| 失败 | 处理异常 | 重试、删除 |

## 结果弹窗统计栏说明

| 指标 | 说明 |
|---|---|
| Chunk 总数 / 父块 / 子块 | 切片结构规模 |
| QA 条数 / 章节覆盖率 | 问题生成的覆盖情况 |
| 平均 / 最低质量分 | 切片质量参考（<65 计为低质量块） |
| LLM 调用数 / Token 消耗 | 处理成本统计 |
| 处理耗时 | 开始到完成的时间 |

## 常见问题

**为什么"导入知识库"按钮不可用？**
只有状态为"完成"或"已入库"时可用；存在未保存的 Chunk 编辑时也会暂时禁用，请先保存。

**导入超时或失败怎么办？**
可稍后点击 **更新知识库** 重试；若反复失败，检查 Embedding 模型服务是否可用。

**修改 Chunk 后知识库会立即更新吗？**
不会。编辑保存只更新处理结果，必须执行 **导入/更新知识库** 后检索数据才会更新。

## 使用提示与边界

- 入库后 AI 问答检索的是 ES 中的数据，务必在修改内容后执行"更新知识库"。
- 密级等标签继承自文件管理页设置；需要变更访问范围请回到文件管理修改密级后重新导入。
- 低质量块（质量分 < 65）建议人工修正后再入库，以提升问答准确率。
