## 功能概述

**运行实例** 展示工作流每一次执行的完整轨迹：运行状态、执行时长、错误信息，以及节点级执行画布、尝试历史、循环批次与事件时间线。您可以在本页查看执行详情、取消活跃实例、重试失败实例与重试循环失败项。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（`automation:run:list` 权限）。
- **前置条件**：工作流已发布并产生过运行（手动运行或触发器触发）。

## 进入路径

主菜单：**自动化中心 → 运行实例**。

## 操作步骤

### 1. 查看运行列表

- 可按**工作流、状态**筛选；列表展示运行 ID、工作流、版本、触发方式、状态、耗时与错误摘要。

### 2. 查看运行详情

点击 **详情**（或双击行）打开抽屉，包含五个页签：

- **执行画布**：节点按状态着色（成功绿 / 失败红 / 运行黄 / 等待蓝），连线展示条件与默认分支；
- **节点**：每个节点的类型、状态、尝试次数、错误信息与起止时间；
- **尝试**：节点各次尝试的编号、执行器、状态与错误；
- **循环批次**：循环节点的批次进度（成功/失败/总数）、并发与限流，可**重试失败项**；
- **时间线**：事件类型与发生时间的完整序列。

### 3. 取消运行

仅**活跃状态**（已创建、排队中、运行中、等待事件、等待定时器、等待重试）可取消；取消后不可恢复。

### 4. 重试运行

仅 **失败（FAILED）** 状态显示重试按钮：按该运行的固定版本创建新的重试运行，不依赖当前草稿。

### 5. 处理循环失败项

循环批次有失败项时，可在批次详情点击 **重试失败项**，失败项重新进入调度。

## 配置项说明

### 运行状态

| 状态 | 说明 | 可操作 |
|---|---|---|
| 已创建 / 排队中 | 已提交等待调度 | 取消 |
| 运行中 | 正在执行节点 | 取消 |
| 等待事件 / 等待定时器 / 等待重试 | 挂起等待 | 取消 |
| 待审批 | 等待人工审批 | 会话中审批 |
| 成功 | 全部节点成功 | - |
| 部分失败 | 部分节点失败但流程完成 | - |
| 失败 | 执行失败 | 重试 |
| 已取消 | 手动或系统取消 | - |

### 循环批次字段

| 字段 | 说明 |
|---|---|
| 批次 ID / 循环节点 | 定位批次 |
| 进度 | 成功项 / 失败项 / 总数 |
| 最大并发 | 同时处理条数 |
| 每秒限流 | 处理速率限制 |

## 常见问题

**为什么运行一直处于"等待事件"？**
工作流包含等待事件/审批节点，正在等待外部回调或审批人操作；处理完成后自动继续。

**"部分失败"和"失败"有什么区别？**
部分失败：失败节点被跳过或已处理，流程最终完成；失败：流程终止。

**重试会使用最新发布版本吗？**
不会。重试按**原运行固定的版本**执行，保证结果可复现。

## 使用提示与边界

- 取消不可恢复：确认任务不再需要后再操作。
- 长时间等待中的运行，可结合"事件记录"确认外部回调是否已到达。
- 运行数据（输入、变量、节点输出）加密存储，仅供有权限的账号查看。
