## 功能概述

**失败任务** 集中处理工作流执行失败产生的**死信**：查看失败类型与原因、对可恢复的失败**安全重试**，或确认无需处理后**放弃死信**，避免失败任务无限堆积。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（`automation:failure:list` 权限）。
- **前置条件**：工作流执行失败且已进入死信通道。

## 进入路径

主菜单：**自动化中心 → 失败任务**。

## 操作步骤

### 1. 查看死信列表

- 可按**运行 ID、状态**筛选；
- 列表展示死信 ID、运行 ID、节点运行 ID、失败类型（tooltip 显示原始错误码）、状态、处理人与时间。

### 2. 安全重试

仅状态为 **待处理（OPEN）** 的死信可操作：点击 **安全重试**，系统按原运行 **固定版本** 执行重试并创建新的重试运行。

> **提示** 安全重试不会修改原运行定义，结果可复现，是恢复失败任务的首选方式。

### 3. 放弃死信

确认无需恢复时点击 **放弃**：关闭死信，不再重试。

### 4. 状态流转

**待处理 → 已重放 / 已放弃**：重放或放弃后死信关闭，不再出现在待办。

## 配置项说明

### 失败类型

| 类型 | 含义 | 建议 |
|---|---|---|
| VALIDATION | 数据校验失败 | 修正输入数据后重试 |
| AUTH | 认证或授权失败 | 检查凭据与权限后重试 |
| RATE_LIMIT | 触发限流 | 等待窗口后重试 |
| TIMEOUT | 执行超时 | 调整节点超时或拆分任务 |
| TRANSIENT | 临时连接故障 | 直接重试通常可恢复 |
| BUSINESS | 业务处理失败 | 按业务逻辑处理 |
| POLICY | 策略拦截 | 检查安全策略 |
| CANCELLED | 任务已取消 | 无需处理 |
| UNKNOWN | 未知故障 | 联系管理员 |

### 状态

| 状态 | 说明 |
|---|---|
| 待处理 | 死信开放，可重试或放弃 |
| 已重放 | 已执行安全重试 |
| 已放弃 | 已确认不再重试 |

## 常见问题

**安全重试和运行实例页的"重试"有什么区别？**
两者都按固定版本执行；失败任务页的重试面向死信（带失败类型分析），运行页重试面向失败运行实例。

**重试后仍然失败怎么办？**
结合失败类型排查根因（凭据、数据、外部系统），修复后再重试；多次失败可考虑调整工作流设计。

**为什么有些死信没有操作按钮？**
只有"待处理"状态的死信可操作；已重放/已放弃的记录只读。

## 使用提示与边界

- 死信是运行失败的最后防线，建议定期处理避免堆积。
- 放弃死信不可恢复，请确认任务确实无需执行。
