## 功能概述

**运行统计** 提供当前租户自动化运行的全局健康视图：吞吐量、队列积压、等待状态、成功率与失败率、重试与死信情况，帮助管理员快速发现积压、高失败率等运行异常，并支持**立即对账**修复运行状态差异。

## 适用角色与前置条件

- **适用角色**：Agent 管理员（`automation:statistics:view` 权限）。
- **前置条件**：租户内已产生自动化运行数据。

## 进入路径

主菜单：**自动化中心 → 运行统计**。

## 操作步骤

### 1. 查看概览指标

顶部指标卡展示：

- **运行总数 / 活跃实例 / 队列积压 / 等待实例**：判断吞吐与积压；
- **成功率 / 失败率**：整体执行健康度；
- **重试次数 / 开放死信**：重试与异常堆积情况。

> **注意** 队列积压（>0）与开放死信（>0）会以黄/红色告警突出显示，建议优先处理。

### 2. 分析耗时指标

查看实例平均耗时、平均排队延迟、平均等待时长与节点平均耗时，定位性能瓶颈（排队过长、节点过慢或等待事件过多）。

### 3. 查看状态分布

状态分布表按运行状态分组展示数量与占比，快速识别大量"等待事件/待审批"等挂起状态。

### 4. 执行对账

点击 **立即对账**：核对最近运行实例与 Flowable 引擎状态并修复可确定的差异（如业务已终态但引擎仍活跃的实例）。系统每 5 分钟自动执行一次。

> **提示** 对账结果展示扫描实例数、已修复数、终态但引擎活跃数与暂无法判定的实例数。

## 配置项说明

### 指标卡

| 指标 | 说明 | 关注点 |
|---|---|---|
| 运行总数 | 累计运行次数 | - |
| 活跃实例 | 正在执行的实例 | 过高说明负载大 |
| 队列积压 | 排队等待调度的实例 | >0 黄色告警 |
| 等待实例 | 挂起（等待事件/定时/审批） | 结合事件记录排查 |
| 成功率 / 失败率 | 整体健康度 | 失败率突增需排查 |
| 重试次数 | 自动重试累计 | 过高说明节点不稳定 |
| 开放死信 | 未处理的失败任务 | >0 红色告警 |

### 耗时指标

| 指标 | 说明 |
|---|---|
| 实例平均耗时 | 单个运行的平均执行时长 |
| 平均排队延迟 | 从提交到开始执行的等待 |
| 平均等待时长 | 挂起状态的平均时长 |
| 节点平均耗时 | 单个节点的平均执行时长 |

## 常见问题

**队列积压持续不降怎么办？**
检查并发与限流配置是否过小、外部依赖（数据库/API/模型服务）是否变慢，必要时拆分或优化工作流。

**对账能解决哪些问题？**
对账可修复运行实例与引擎状态不一致（如进程重启导致的悬空状态）；无法判定的实例会保留待人工处理。

**为什么统计里看不到新运行？**
统计按租户汇总，生成时间戳展示在页面上；刚触发的运行可能需要等待统计刷新。

## 使用提示与边界

- 告警指标（积压、死信）应纳入日常巡检，避免故障累积。
- 对账为运维性操作，会自动执行，无需频繁手动触发。
