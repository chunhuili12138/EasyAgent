## 功能概述

**部门管理** 维护租户的组织架构树：部门层级、负责人、联系电话与启用状态。部门是文档 ACL、数据源/工具授权范围与用户归属的基础组织单元。

## 适用角色与前置条件

- **适用角色**：租户管理员（`system:department:list` 权限）。

## 进入路径

主菜单：**系统管理 → 部门管理**。

## 操作步骤

### 1. 新建部门

1. 点击 **新建**（或在某部门行点击 **新增下级** 创建子部门）。
2. 选择上级部门（留空为根部门），填写部门名称、负责人、联系电话与排序。
3. 保存后部门出现在组织树中。

### 2. 编辑部门

点击 **编辑** 修改负责人、电话、排序或状态；部门名称支持修改。

### 3. 删除部门

点击 **删除**：存在**子部门**时禁止删除（需先删除/迁移下级）；删除后该部门下用户的归属关系需重新调整。

> **注意** 停用部门不影响历史数据，但新授权选择中不可见。

## 配置项说明

| 字段 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| 上级部门 | 否 | 根部门 | 树形选择；留空为一级部门 |
| 部门名称 | 是 | - | 部门唯一标识名 |
| 负责人 | 否 | - | 部门负责人姓名 |
| 联系电话 | 否 | - | 联系电话 |
| 排序 | 否 | 1 | 数字越大越靠后（min=1） |
| 状态 | 否 | 启用 | 启用 / 停用 |

## 常见问题

**为什么删除部门时提示"存在子部门"？**
有下级部门时不允许直接删除，请先删除或调整子部门的上级，再执行删除。

**部门删除后文档授权会怎样？**
历史 ACL 数据保留但失去实际意义；请及时为相关文档重新设置授权范围。

**部门层级最多几级？**
平台支持任意层级树；实际建议控制在 3–4 级以内，便于管理与授权。

## 使用提示与边界

- 部门树在文件上传、Schema 授权、工具授权等场景通用，命名建议规范统一。
- 调整部门层级会影响其下用户的 ACL 归属，请在非业务高峰操作。
