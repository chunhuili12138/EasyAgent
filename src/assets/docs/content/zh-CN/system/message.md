## 功能概述

**消息通知**展示当前登录用户收到的系统消息、文档解析/处理结果和其他业务提醒。消息按当前用户和当前租户隔离，用户只能查看自己的消息。

## 进入路径与范围

- 主菜单：**账号与组织 → 消息通知**。
- 登录后必须处于具体租户；系统管理员处于全局（未选择租户）时也可以查看自己的全局消息。
- 页面不会展示其他用户或其他租户的消息。

## 查询消息

1. 在标题框输入关键词，关键词只匹配消息标题。
2. 按消息类型筛选：信息、警告、成功、错误、文档解析或文档处理。
3. 按阅读状态筛选**已读**或**未读**，点击**搜索**；点击**重置**清空筛选条件。
4. 列表展示标题、内容、类型、阅读状态和创建时间。

## 阅读操作

- 点击单条消息的**标记已读**，只更新当前消息。
- 点击**全部已读**并确认，将当前范围内的未读消息全部标记为已读。
- 已读消息不会重复执行标记操作。当前页面不提供删除、编辑或手动发送消息功能。

## 消息类型

| 类型 | 用途 |
|---|---|
| 信息 | 一般系统提示 |
| 警告 | 需要关注的提醒 |
| 成功 | 操作完成或结果成功 |
| 错误 | 操作失败或异常提醒 |
| 文档解析 | 文件解析阶段的结果 |
| 文档处理 | 切分、向量化或入库等处理结果 |

## 常见问题

**为什么没有看到刚产生的消息？**

确认租户切换正确，点击搜索或刷新页面；消息列表按创建时间倒序加载。

**标记已读后还能恢复未读吗？**

当前页面没有恢复未读的操作，请在确认前再执行**全部已读**。

**为什么只能看到自己的消息？**

这是服务端的用户和租户隔离规则，管理员也不能通过该页面读取其他用户的个人通知。
