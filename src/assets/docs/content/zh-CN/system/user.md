## 功能概述

**用户管理** 维护租户内的账号体系：创建用户（手机号即登录账号）、分配角色与组织关系（部门+岗位）、启停账号与重置密码。用户权限由**角色**决定，数据范围由**部门/岗位**决定。

## 适用角色与前置条件

- **适用角色**：租户管理员（`system:user:list` 权限）。
- **前置条件**：已存在部门、岗位与角色数据。

## 进入路径

主菜单：**系统管理 → 用户管理**。

## 操作步骤

### 1. 新建用户

1. 点击 **新建**，填写手机号（登录账号）、昵称、邮箱与初始密码。
2. 分配**角色**（至少一个，决定菜单权限）。
3. 分配**部门与岗位**（成对分配，部门选定后岗位自动过滤）。
4. 确认用户归属**租户**：只有系统管理员可以绑定多个租户；租户管理员创建或编辑用户时只能绑定当前租户。
5. 保存后用户即可使用手机号+密码登录。

### 2. 编辑用户

- 可修改昵称、邮箱、状态、角色与组织关系；
- **手机号（账号）不可修改**。

### 3. 重置密码

点击 **重置密码** 为用户设置新密码（不要求旧密码），重置后通知用户及时修改。

### 4. 停用/删除

- **停用**：用户无法登录，数据保留；
- **删除**：账号从租户移除（如已有业务数据，建议改用停用）。

## 配置项说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 手机号 | 是 | 即登录账号，新建后可登录，编辑时不可改 |
| 昵称 | 否 | 展示名称 |
| 邮箱 | 否 | 通知与找回凭证 |
| 初始密码 | 是（新建） | 6–18 位，必须包含字母、数字和特殊符号，且不能包含空白 |
| 状态 | 否 | 启用 / 停用（默认启用） |
| 租户 | 是 | 仅系统管理员可多选；租户管理员固定为当前租户 |
| 角色 | 是 | 至少一个角色，决定可访问菜单 |
| 部门 | 与岗位成对 | 决定数据范围与 ACL 归属 |
| 岗位 | 与部门成对 | 仅显示所选部门下的启用岗位 |

> **注意** 部门与岗位必须同时为空或同时选中，避免出现"有岗位无部门"的悬挂关系。

## 常见问题

**用户登录失败但密码正确？**
请检查账号状态是否为"启用"、是否归属当前租户（登录页需选择对应租户）。

**为什么用户看不到某些菜单？**
菜单由角色决定：请确认已分配包含目标菜单权限的角色。

**如何让一个用户属于多个部门？**
当前一个用户仅支持一个部门+岗位；如需多部门权限，请结合角色与 ACL 授权范围配置。

## 使用提示与边界

- 手机号即账号，创建后不可修改；务必核对后提交。
- 停用账号可随时恢复，删除不可恢复，谨慎操作。
- 初始密码由管理员设置，建议用户首次登录后修改。
